# OpenConfession

Telegram-бот: личное сообщение сразу публикуется в канале без модерации.
Python 3.11+, без сторонних зависимостей.

## Правила

- После успешной публикации пользователь ждёт 15 секунд.
- При ранней попытке бот сообщает оставшееся время с округлением вверх.
- 5 входящих сообщений от одного аккаунта в одну календарную секунду Telegram
  блокируют публикацию на 3600 секунд. У Telegram время сообщения имеет точность
  до секунды: это фиксированные секундные окна, не скользящее окно.
- Считаются также команды и отклонённые сообщения. Повторные попытки во время
  блокировки не продлевают её. Остальные пользователи не блокируются.
- Ответы об ограничениях отправляются не чаще раза в 2 секунды; уведомление
  о новой часовой блокировке отправляется сразу.
- Состояние и позиция чтения обновлений сохраняются в SQLite.

Сообщения копируются через [copyMessage](https://core.telegram.org/bots/api#copymessage)
без ссылки на исходного отправителя. Текст, подписи и сами вложения могут содержать
указанные пользователем личные данные. Поддерживаются копируемые Telegram типы:
текст, отдельные фото, видео, голосовые, стикеры и документы. Альбомы отклоняются;
файлы нужно отправлять отдельно. Команды показывают справку и не публикуются.

## Запуск

1. Создайте бота через [BotFather](https://t.me/BotFather).
2. Добавьте его администратором канала с правом публикации сообщений.
3. Задайте переменные окружения и запустите один экземпляр:

```bash
export BOT_TOKEN='токен от BotFather'
export CHANNEL_ID='@your_channel'
export DATABASE_PATH='data/bot.sqlite3'
python3 bot.py
```

Для закрытого канала укажите числовой ID вида `-100...` вместо имени.
`.env.example` — образец настроек; программа сама `.env` не читает.
Токен не добавляйте в git. Для постоянной работы нужен постоянно работающий
сервер или компьютер. Сохраняйте каталог `data` между перезапусками.

Используется long polling. Активный webhook или второй экземпляр того же бота
мешают работе. При запуске проверяются токен, тип канала и право публикации.

## Проверка

```bash
python3 -m unittest -v
```

Тесты работают без Telegram и токена: проверяют публикацию, границы таймера,
часовую блокировку, независимость пользователей, перезапуск и ошибки API.

## Ограничения первой версии

Один процесс последовательно обрабатывает сообщения; для большого потока
потребуется очередь. Проверка частоты идёт по ID аккаунта и не объединяет разные
аккаунты одного человека. Уже опубликованные сообщения при блокировке не удаляются.

Перед обработкой сохраняется позиция обновления: при аварийном завершении возможно
потерять текущее сообщение, зато оно не будет автоматически отправлено повторно.
При сетевой ошибке публикация может уже состояться: бот просит проверить канал,
не повторяет запрос и включает 15-секундную паузу. Гарантии exactly-once нет.
База хранит ID пользователей и таймеры, но не содержимое признаний.
